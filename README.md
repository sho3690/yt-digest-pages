# YouTube Digest — 閲覧用

登録したYouTubeチャンネルの新着動画を、自宅のMacが毎週まとめて要約したものを
読むための小さなWebアプリです。ここはその**閲覧専用の控え**です。

公開URL: https://sho3690.github.io/yt-digest-pages/

## これは何か

- 要約を作っているのは自宅のMac上の自動処理です（本体 `yt-digest` は非公開）
- ここには**作り終えた閲覧アプリ（HTML/CSS/JS と要約データ）だけ**が置かれています
- iPhoneのホーム画面に追加すると、アプリのように開けます

## 置いてあるもの / 置いていないもの

| | |
|---|---|
| 置いてある | 週ごとの要約本文、動画のタイトル・チャンネル名・YouTubeへのリンク |
| 置いていない | 字幕の全文、認証情報、既読やスターの記録（端末内にだけ保存されます） |

## 要約について

要約は**AIが字幕から自動生成したもの**で、人手による確認を経ていません。
誤りが含まれる可能性があります。内容は必ず元の動画でお確かめください。
動画の著作権は各チャンネルに帰属します。

## 更新

毎週土曜13時ごろ、自動で更新されます（`yt-digest` の GitHub Actions が push します）。
