    GitHubの画面を開かずに送る設定

    GitHubで「このアプリ専用の鍵」を1回だけ作って貼り付けると、以後はGitHubの画面を開かずにアプリ内で変更を送れます。鍵はこの端末の中にだけ保存され、リポジトリには入りません。

    1. GitHubの鍵の作成ページを開く（ログインが必要）
    2. Token name に「YouTube Digest」と入れ、Expiration は「1年」などにする
    3. Repository access で「Only select repositories」を選び、sho3690/yt-digest を選ぶ
    4. Permissions → Repository permissions の Issues を「Read and write」にする（他は触らない）
    5. 「Generate token」を押し、表示された鍵をコピーして下に貼る

    この鍵でできるのは、このリポジトリに Issue を書くことだけです。要約の中身や自宅Macの処理には触れません。鍵はGitHubの「Settings → Developer settings」からいつでも無効化できます。
